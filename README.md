# Food Lover — Restaurant Website Concept

A responsive, single-page restaurant website concept built with HTML5 and CSS3. It demonstrates a typical restaurant marketing site with a hero banner, restaurant introduction, offers, menu, opening hours, gallery, and contact section.

## Features
- Responsive navigation and hero section.
- About and special-offers sections.
- Two-column food menu with dish imagery and prices.
- Opening-hours section and image gallery.
- Contact information and an accessible contact-form demo.
- Responsive layouts for tablet and mobile screens.

## Tech Stack
- HTML5
- CSS3 (Flexbox and media queries)
- Font Awesome 6.7.2 (CDN)

## Run Locally
1. Clone this repository.
2. Keep index.html, style.css, and the images/ folder together.
3. Open index.html in a browser or use VS Code Live Server.

## Important Notes
- This is a front-end practice project, not a real restaurant booking or ordering system.
- The contact form only displays a local demo message; it does not send or store data.
- Menu items, prices, restaurant details, and opening hours are illustrative sample content.
- The Book a Table action was changed to navigate to the contact section because no booking backend exists.

## Main Files
- index.html — page content and form-demo interaction.
- style.css — visual design and responsive styling.
- images/ — logo, background, food, and gallery images.
